# September 11 retest and remaining acceptance gaps

This supplements the September 9 audit. The reviewed base is `7c07138`.
GitHub and Forgejo main matched at the initial comparison. Local evidence used
a fresh Streamlit process and an isolated copy of the bundled SQLite seed
(18 books, 627 blocks, 9,119 chunks). Cloud showed different corpus counts
(18 / 729 / 9,168) and no build caption; it is not verified as this checkout.
Screenshots and local tests are not Cloud deployment evidence.

## Fixes in this change

- Repeated citations to one chunk caused `StreamlitDuplicateElementKey`.
  A regression test reproduced the reported exception before the fix. Each
  citation now has a distinct source button; both quotes remain visible and
  either button opens the source. Ask and Mentor share this renderer.
- SceneHit has no section/page/ordinal fields. The UI incorrectly defaulted
  every label to passage 1. Labels now resolve source metadata once per unique
  anchor per search, cached across reruns. An unavailable source displays an
  unspecified passage rather than an invented number.
- Mentor learning activities are not book titles. Matching “Read the key
  passage” against the shelf failed even with a valid Smith citation. Grounded
  plans now explicitly offer to queue their cited shelf books, using validated
  citation book IDs checked against the shelf. The UI explains that activities
  remain in the plan. Uncited curated plans retain title matching.
